# dds-datamodels-gva

This repository contains the IDL data model for the GVA Reference Model-9.2.0

## Generated IDL
1. The IDL for the complete model is contained in the IDL folder.
2. The IDL has been generated using GVA_PIM_Translator Version 3.0 & GVA_PSM_Translator Version 2.5.

## This Release
1. This release of the build set differs from Version-9.1.0
2. Audio Domain has been added. This forms part of the Multimedia Composite Domain along with Multimedia_Routing and Video Domains.
3. Automotive_Message_Set_Specification Domain has been added.
4. Battlespace_Objects Domain has been added
5. PIM HTML documentation has now been generated on a module-by-module basis rather than for the entire buildset. This makes it easier to browse.

**NOTE:** The rules defining topic names are specified in the GVA Development and Deployment Standards and Guidelines v2.0
